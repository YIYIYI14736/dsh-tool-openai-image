# dsh-tool-openai-image

An OpenAI-compatible image-generation tool plugin for **DeepSeek Harness 0.2+**, including the official Desktop application.

The plugin registers an agent-facing `image_generate` tool, calls an OpenAI-compatible `/images/generations` endpoint, stores generated bytes through the Harness attachment service, and returns durable images that can be displayed in the conversation.

## Features

- OpenAI-compatible `POST /images/generations` requests.
- API keys resolved through the Harness credentials service.
- Supports `b64_json`, data URLs, and HTTP(S) image URLs.
- Supports PNG, JPEG, WebP, and GIF responses.
- Stores output through `ctx.attachments.saveImage()` rather than putting base64 in session logs.
- Rejects private/local image download URLs and limits downloaded image size.
- Supports cancellation and configurable request timeouts.
- Tested with DeepSeek Harness `0.2.0-rc.2`.

## Requirements

- DeepSeek Harness `>=0.2.0-rc.2`
- An OpenAI-compatible provider implementing `/v1/images/generations`
- A configured API-key credential reference

## Installation

Clone this repository, then install it into the Desktop profile from a DSH Desktop terminal:

```powershell
git clone https://github.com/YIYIYI14736/dsh-tool-openai-image.git
cd dsh-tool-openai-image
dsh plugin --profile desktop add .
```

Restart DeepSeek Harness Desktop after installation.

For local development, an absolute path also works:

```powershell
dsh plugin --profile desktop add F:\path\to\dsh-tool-openai-image
```

## Configuration

The default [`cordis.patch.yml`](./cordis.patch.yml) uses OpenAI-compatible defaults:

```yaml
- insert:
    - id: openai-image-tool
      name: dsh-tool-openai-image
      config:
        baseURL: "https://api.openai.com/v1"
        endpoint: "/images/generations"
        apiKeyEnv: "OPENAI_API_KEY"
        defaultModel: "gpt-image-1"
        defaultSize: "1024x1024"
        timeoutMs: 180000
        maxImageBytes: 26214400
        responseMode: "auto"
```

For a personal gateway, change only the non-secret settings, for example:

```yaml
config:
  baseURL: "https://gateway.example.com/v1"
  endpoint: "/images/generations"
  apiKeyEnv: "MY_IMAGE_API_KEY"
  defaultModel: "my-image-model"
```

Store the actual key in Harness credentials under the name configured by `apiKeyEnv`. Do **not** put an API key in `cordis.patch.yml`.

### Configuration fields

| Field | Default | Description |
|---|---|---|
| `baseURL` | `https://api.openai.com/v1` | Provider base URL |
| `endpoint` | `/images/generations` | Image-generation endpoint relative to the base URL |
| `apiKeyEnv` | `OPENAI_API_KEY` | Harness credential reference |
| `defaultModel` | `gpt-image-1` | Default image model ID |
| `defaultSize` | `1024x1024` | Default requested image size |
| `timeoutMs` | `180000` | Request timeout in milliseconds |
| `maxImageBytes` | `26214400` | Maximum bytes accepted for one returned image |
| `responseMode` | `auto` | `auto`, `base64`, or `url` |

## Usage

Ask the agent naturally:

```text
Generate a cinematic image of a futuristic city in the rain.
```

Or explicitly request the tool:

```text
Call image_generate and create a 1024x1024 minimalist blue icon.
```

Tool parameters:

- `prompt` — required image prompt
- `model` — optional model override
- `size` — optional size override
- `n` — image count from 1 to 4
- `quality` — provider-specific quality value
- `background` — provider-specific background value
- `output_format` — `png`, `jpeg`, or `webp`

## Uninstall

```powershell
dsh plugin --profile desktop remove dsh-tool-openai-image
```

Restart Desktop after removal.

## Security

- API keys are resolved at request time and are not stored in this repository.
- Complete base64 image payloads are not written into model-facing text.
- Remote image downloads reject literal localhost, loopback, link-local, and private IP addresses.
- Provider URLs should still be treated as untrusted and configured only for services you trust.
